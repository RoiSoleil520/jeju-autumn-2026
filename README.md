# 济州，晚秋见。

2026 年 11 月 20—24 日，3 人济州旅行手册。依照提供的攻略：21 日城山日出峰→牛岛→涉地可支，22 日涯月→汉潭步道→挟才→涯月日落，23 日秋色三选一→市区。

- 五天时间表、风雨替代方案、秋色选择、Naver 地图搜索。
- 美食建议、营业日提示、设备本地行前清单、预算估算。
- 全部日期打印、文字行程下载、核心内容离线缓存。
- 不依赖构建工具、第三方脚本或在线字体；直接由 GitHub Pages 托管。

## 本地预览

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/`。直接双击 HTML 也能看核心交互，Service Worker 需要 HTTP / HTTPS。

## 更新

`data.js` 为行程、地点、餐厅、清单及来源。`app.js` 负责交互，`style.css` 包含响应式和打印样式。修改离线内容后递增 `sw.js` 的缓存版本。所有部署资源使用相对路径，兼容项目级 Pages。

GitHub Pages 设置：Deploy from a branch → `feat/jeju-trip-20261112` → `/ (root)`。页面地址：<https://RoiSoleil520.github.io/jeju-autumn-2026/>。

## 信息边界

资料核验：2026-11-12。路线来自用户提供攻略；航班来自订单截图；住宿区域由用户确认并与房源公开介绍交叉核对。没有公开订单截图、护照、具体门牌、入住密码、预订号或私人联系方式。没有预订或购买旅行产品。

天气是月度气候参考，不是 20—24 日逐日预报。船班、商家退改、具体集合点、公交站点与实时营业需要临行确认。车程和预算是估算。网页内附直接来源链接，官方资料优先于社交媒体体验。
