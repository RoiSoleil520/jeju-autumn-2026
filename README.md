# 济州，晚秋见。

2026 年 11 月 20—24 日，3 人济州旅行手册。最新路线：21 日市区（晚起汤面→国立济州博物馆→东门市场→塔洞或地下商街→莲洞晚餐），22 日东线（城山→牛岛→涉地），23 日西线（涯月→汉潭→挟才→海景咖啡），当晚 19:40—20:30 完成行李与次日送机确认。

- 首页显示“现在／接下来”，按韩国时间自动选择日期和时段；手动浏览不会被每分钟更新打断，可一键回到当前安排。
- 行前准备 + 五天时间线，早餐、午餐、咖啡、晚餐、随身物品和检查项放在对应时段内。
- 支持指定日期时间预览、切换风雨方案、市区下午天气二选一、餐厅选择和新增自己的 30 分钟安排。
- 默认大字版，顶部右侧“字号”入口默认收起，点开可切换大字舒适／普通紧凑，字号、卡片留白、行距、控件及图标同步切换，并在当前浏览器记住选择；选择后自动收起，也可点外侧或按 Esc 关闭。字号设置独立于清单和行程记录。
- 行程、餐饮、小店和清单采用短句，保留关键时间、船况、证件与接送提醒。底部导航使用统一线条图标，始终配文字。
- 保留餐饮备选、完整准备清单、预算估算和 Naver 地图。
- 14 组小店按区域直接展示，关联西线和市区时段；保留用户截图中的 14 张配图，行程中的店铺入口以弹框显示介绍、地图与配图，关闭后保留原页面位置；弹框内仍可点击图片放大，用关闭按钮、Esc 或点遮罩退出。
- 全部日期打印、文字行程下载、核心内容离线缓存。
- 不依赖构建工具、第三方脚本或在线字体；直接由 GitHub Pages 托管。

## 本地预览

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/`。直接双击 HTML 也能看核心交互，Service Worker 需要 HTTP / HTTPS。

## 更新

`data.js` 为行程、地点、餐厅、清单及来源。`schedule.js` 定义明确的韩国时间起止区间、餐饮和准备事项绑定、跨午夜归属与当前/下一项判断。`shops.js` 为用户截图中的小店参考数据，`assets/shops` 为截图内配图的提取文件；营业、地址、库存与价格未逐店核实。`appearance.js` 在样式加载前恢复字号，并处理字号切换。`app.js` 负责交互，`style.css` 包含响应式和打印样式。

使用 Node 22 或更新版本运行时间规则检查：`node --test tests/schedule.test.cjs`。覆盖中韩时差、跨午夜、时段边界、风雨替代与自定安排。修改离线内容后递增 `sw.js` 的缓存版本。页面脚本、样式的版本参数应与 `sw.js` 核心文件列表保持一致，避免旧缓存混用新界面。所有部署资源使用相对路径，兼容项目级 Pages。

GitHub Pages 设置：Deploy from a branch → `feat/jeju-trip-20261112` → `/ (root)`。页面地址：<https://RoiSoleil520.github.io/jeju-autumn-2026/>。
